# Grant Eligibility Matcher

Match citizens, businesses and nonprofits to eligible grants and public funding programs — semantic search across programs, eligibility scoring and application assistance.

**Free & open-source (MIT).** Part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/) — Batch 79: GovTech & Smart City AI.

## Features
- Semantic search across federal/state/municipal programs
- Eligibility scoring with explainable criteria
- Deadline and requirement tracking
- Application draft assistance
- Alerts for newly published programs
